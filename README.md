# 버티는 생활권: 베이커리 신규 출점 전략

사모펀드가 보유한 베이커리 전문점(가상의 클라이언트)을 위한 신규 출점 제안서입니다.
서울 열린데이터광장 상권분석서비스 22개 분기(2021년 1분기~2026년 2분기), 1,650개 상권 데이터를 썼습니다.

- 웹페이지: `index.html` (GitHub Pages)
- 2분 발표 영상: `assets/pitch.mp4`

## 결론

**추천 입지는 강동구 둔촌역 상권입니다.** 3년 뒤를 실제로 맞힌 지표 6개로 채점하면 서울 337개 제과점 상권 중 14위(상위 4%)이고, 점포당 제과점 매출은 연 5.6억 원(상위 9%)입니다.

| 항목 | 제안 | 근거 데이터 |
|---|---|---|
| 입지 | 5호선 둔촌동역 ~ 둔촌역전통시장 퇴근 동선 1층 | 성장성 점수 74.1, 제과점 시장 74.2억 원/년, 올림픽파크포레온 12,032세대 |
| 공간 | 두 번 굽는 동네 식탁 (66㎡, 좌석 8석) | 17시 이후 매출 38.4%, 커피 시장은 빵의 0.5배 |
| 메뉴 | 식사빵 35%, 하프 사이즈, 16:30 두 번째 굽기 | 50대 이상 매출 50.7%, 객단가 9,513원 |
| 손익 | 3년차 매출 6.65억, 영업이익률 8.8%, 권리금 포함 투자 3.5억 원 회수 약 4.1년 | 상권 점포당 평균 5.6억 원에서 출발, 비용은 DART 감사보고서·한국부동산원·최저임금위원회 벤치마크와 대조 |

## 지표 설계

성장 = 유입(사람) × 고객 × 체력(가게) × 흐름(매출). 후보 지표 20개를 네 번의 백테스트로 검증해 6개만 채택했습니다.

| 축 | 지표 | 가중치 |
|---|---|---|
| 유입 | 유동인구 증가율 | 15% |
| 고객 | 50대 이상 매출 비중 | 25% |
| 체력 | 외식업 폐업률(역) | 20% |
| 체력 | 운영 점포 평균 영업 개월 | 15% |
| 흐름 | 제과점 매출 증가율 | 15% |
| 흐름 | 분기 매출 안정성 | 10% |

가중치 = 평균 IC × 부호 일관성, 5%p 단위 반올림. 2023년 2분기 채점 → 2026년 2분기 실제 성장률 기준으로 점수 상위 20%는 −2.2%, 하위 20%는 −21.4%(중위)였습니다. 같은 기간 과거 매출 증가율 상위 20%는 −10.6%로 다섯 그룹 중 최하위였습니다.

## 재현

```bash
pip install pandas numpy
# data.seoul.go.kr 에서 받은 인증키를 환경변수 SEOUL_API_KEY 로 지정
python analysis/01_fetch.py     # 원천 데이터 수집 (약 10분, data/raw)
python analysis/02_panel.py     # 상권×분기 패널
python analysis/03_score.py     # 지표·백테스트·점수 (data/result.json, scores.csv, ic_table.csv)
python analysis/04_profile.py   # 웹페이지용 수치 (data/site.json)
pip install edge-tts playwright imageio-ffmpeg
python video/build.py           # 발표 영상 (assets/pitch.mp4)
```

원천 데이터(`data/raw`, 약 100MB)는 저장소에 넣지 않았습니다. 인증키도 저장소에 없습니다.

## 한계

- 추정매출은 카드 결제 기반 추정치입니다.
- 지표 선택과 가중치를 같은 백테스트로 정했습니다. 동일 가중으로도 IC 0.15~0.22가 유지되지만 2027년 데이터로 재검증이 필요합니다.
- 손익의 비용은 공시·통계 벤치마크에 맞췄습니다(인건비 30.0%: 성심당 31.1%·아티제 30.4%, 임차료 ㎡당 8.3만 원: 천호 소규모 상가 5.79만 원). 둔촌동 자체의 임대료 통계는 없어 실제 매물 조건으로 교체해야 합니다. 수도광열비·포장비·설비비는 대조 자료가 없는 가정값입니다.
- 3년차 매출 6.65억 원은 3.3㎡당 3,331만 원으로 파리바게뜨 서울 가맹점 평균(3,089만 원)보다 8% 높은 생산성을 전제합니다.
